## 🔧 STAR Method Template

Use this for behavioral questions:

**S**ituation (2-3 sentences): Set the context  
**T**ask (1-2 sentences): Your specific responsibility  
**A**ction (3-4 sentences): What you did - BE SPECIFIC  
**R**esult (2-3 sentences): Outcome - QUANTIFY if possible

**Example:**
- Situation: "In my scheduling project, we needed drag-and-drop functionality"
- Task: "I was responsible for implementing it within a week"
- Action: "I researched HTML5 Drag API, built a proof-of-concept, integrated it with validation logic, and added visual feedback"
- Result: "Delivered on time, worked smoothly across devices, became a highly-used feature"
