## 🎯 STAR Method Template

*For behavioral questions - write this down:*

**S** = Situation (2-3 sentences of context)  
**T** = Task (Your specific responsibility)  
**A** = Action (What YOU did - be specific!)  
**R** = Result (Outcome - quantify if possible)

*Example:* "In my scheduling project (S), I needed to implement drag-and-drop (T). I researched the HTML5 Drag API, built a proof-of-concept, then integrated it with validation logic and visual feedback (A). Delivered on time, works smoothly across devices, became most-used feature (R)."
